## Route SEO

- `src/routes/__root.tsx` supplies global title, description, Open Graph defaults, Twitter card, font links, favicon, viewport, and charset.
- Each implemented page defines route-level title/description/Open Graph metadata.
- Dynamic project/job detail pages build metadata from local arrays.
- There is no Laravel-ready canonical URL, sitemap, structured data, or dynamic social image implementation.

## Route Tree Notes

- `src/routeTree.gen.ts` is generated and must not be manually edited.
- Parent route files `projects.tsx` and `careers.tsx` use nested outlets/children.
- The current generated tree should be regenerated by the frontend tool before any route migration baseline is taken.
